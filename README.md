# MyFeed

ブラウザ拡張として動作するローカル完結型のフィードリーダーです。

## Current Version

**v0.1.12**

- WebサイトのRSS / Atom
- Google Newsの検索キーワード
- Xアカウント（Nitter RSS）
- IndexedDBへのローカル保存
- 72時間キャッシュ（お気に入りは保持）
- カスタムカテゴリ / フィードのドラッグ移動 / フォルダ開閉
- フォルダ自体をドラッグ＆ドロップで並び替え
- フォルダ移動時にドロップ位置（上 / 下）を表示
- 未読件数表示
- 左カラム上部の「すべて / 未読 / お気に入り」を固定
- お気に入りを既存カテゴリ（フォルダ）ごとに絞り込み表示
- JSONエクスポート / インポート
  - 登録フィード
  - フォルダ構成・順序・開閉状態
  - テーマ等の設定
  - お気に入り記事
- 重複記事のローカル類似判定と自動整理
- 画像付きカード / コンパクト表示
- ライト / ダーク / ブラウザ追従テーマ
- 上部操作エリア固定

## インポート・エクスポート

設定画面の「インポート・エクスポート」からJSONバックアップを作成できます。

通常の72時間記事キャッシュはバックアップしません。お気に入り記事はバックアップ対象です。
インポート時は現在のフィード構成・設定を置き換え、通常記事キャッシュをクリアしたうえでお気に入り記事を復元します。

## Edgeへの読み込み

1. このリポジトリをダウンロードまたはClone
2. Edgeで `edge://extensions/` を開く
3. 「開発者モード」をON
4. 「展開して読み込み」を選択
5. リポジトリ内の `src` フォルダを指定

## ファイル構成

- `src/manifest.json` : Edge拡張機能設定
- `src/service-worker.js` : 拡張機能アイコン押下時の画面起動
- `src/dashboard.html` : MyFeed画面
- `src/style-base.css` / `src/style-features.css` / `src/style-v011.css` : デザイン
- `src/dashboard-1.js` ～ `src/dashboard-5.js` : フィード取得・表示・重複判定・お気に入りカテゴリ・バックアップなどの処理
