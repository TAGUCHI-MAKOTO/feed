# MyFeed

ブラウザ拡張として動作するローカル完結型のフィードリーダーです。

## Current Version

**v0.1.31**

## 主な機能

- Webサイトの RSS / Atom / RSS 1.0 RDF
- Google News の検索キーワード
- Xアカウント（Nitter RSS）
- YouTubeチャンネルURLの登録
  - `https://www.youtube.com/@handle` をそのまま登録可能
  - `/channel/UC...` / `/user/...` / `/c/...` に対応
  - YouTube公式Atomへ自動変換
  - チャンネルIDは `UC` + 22文字の24文字で厳密に検証
  - 429 / 5xx / タイムアウトなど一時エラー時は短時間で再試行
  - 旧バージョンの不正IDは、元チャンネルURLが残っていれば再取得を試行
- 1入力欄の自動判定登録
  - URL → WEB / RSS
  - YouTube URL → YouTube
  - X URL / `@account` → X
  - その他 → Google Newsキーワード
- WebサイトURLからRSS / Atomを自動探索
- フィード表示名の自動取得・ダブルクリック変更
- 同一フィードの二重登録抑止

## 左カラム / カテゴリ

- 「フィードを登録」「カテゴリを管理」「設定」を分離
- カスタムカテゴリ / フィードのドラッグ移動
- フォルダ自体のドラッグ並び替え
- 「未分類」は常に最上部へ固定
- フォルダアイコンは4Kでも見やすい `📁 / 📂`
- 左カラム幅を230～460pxで変更可能
- フィードごとのサイトアイコン表示
- 未読件数表示
- 「すべて / 未読 / お気に入り」を上部固定

## v0.1.30: 未読優先の自動ソート

表示上の順番を自動で次のように整理します。

- 記事：**未読 → 既読**
- フィード：**未読あり → 未読0件**
- フォルダ：**未読あり → 全件既読**
- 同じ未読状態の中では、これまでの手動順を維持
- 新着が来たフィード / フォルダは自動で未読側へ戻る
- 「未分類」は従来どおり最上部固定

## v0.1.31: Edge Copilot向けページ分離

フィードを切り替えた際にCopilotが前のフィード内容を要約することがあったため、フィード / フォルダ切替をSPA内の表示差し替えから**実ページ遷移**へ変更しました。

例：

```text
dashboard.html?view=source&source=<SOURCE_ID>&ctx=<TIMESTAMP>
```

- フィードごとに固有URLへ遷移
- フォルダも固有URLへ遷移
- `ctx` を毎回更新し、ブラウザ側から新しいページ文脈として認識されやすくする
- 再読み込み後はURLから選択中フィード / フォルダを復元
- 重複記事の詳細も現在表示中のフィード / フォルダ / 検索条件だけに限定
- ページタイトルを `フィード名 | MyFeed` に同期
- ページ要約 / アクセシビリティ向けに現在表示中の文脈を付与

## フィードヘルスチェック

- 取得失敗時はフィード横に赤い `!` を表示
- `!` にマウスを乗せると直近エラー内容・日時を確認可能
- 最後の失敗より後に取得成功していれば古いエラー印を自動解除
- 記事の `fetchedAt` も成功判定に利用
- RSS / Atom / RDFらしいURLは、登録時に取得できなくてもURLを書き換えず保存可能
- 自動修復 / URL自動書き換えは廃止

## その他

- IndexedDBへのローカル保存
- 72時間キャッシュ（お気に入りは保持）
- お気に入りを既存カテゴリごとに絞り込み
- JSONエクスポート / インポート
- 重複記事のローカル類似判定と自動整理
- 画像付きカード / コンパクト表示
- ライト / ダーク / ブラウザ追従テーマ
- 上部操作エリア固定
- MyFeedブランド：緑の `MF` + `MyFeed`
- 緑MFアイコンのデザインソース：`src/assets/myfeed-icon-source.svg`

> Chrome / Edge のmanifestアイコンはSVG非対応のため、配布ZIPでは緑MFデザインをPNG化して使用しています。リポジトリにはデザインソースSVGを保存しています。

## インポート・エクスポート

設定画面からJSONバックアップを作成できます。

通常の72時間記事キャッシュはバックアップ対象外です。お気に入り記事はバックアップされます。
インポート時は現在のフィード構成・設定を置き換え、通常記事キャッシュをクリアしたうえでお気に入り記事を復元します。

## Edgeへの読み込み

1. このリポジトリをダウンロードまたはClone
2. Edgeで `edge://extensions/` を開く
3. 「開発者モード」をON
4. 「展開して読み込み」を選択
5. リポジトリ内の `src` フォルダを指定

## ファイル構成

- `src/manifest.json` : Edge拡張機能設定
- `src/service-worker.js` : 拡張機能アイコン押下時の画面起動
- `src/dashboard.html` : MyFeed画面
- `src/style-base.css` / `src/style-features.css` / `src/style-v011.css` / `src/style-v015.css` / `src/style-v022.css` / `src/style-v031.css` : デザイン
- `src/dashboard-1.js` ～ `src/dashboard-13.js` : フィード取得・表示・重複判定・カテゴリ・バックアップ・ヘルスチェック・YouTube対応・未読優先・Copilot向け実ページ遷移など
- `src/assets/myfeed-icon-source.svg` : 緑MFアイコンのデザインソース
